# Teachers' Day Webpage

Open `index.html` in your browser to view the responsive Teachers' Day page. It's mobile-friendly and uses Tailwind CDN for styling.

If you want to run a simple local server (recommended) from PowerShell or CMD:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/` and click `index.html`.

Files added:
- `index.html` — main page
- `styles.css` — small additional styles
- `script.js` — modal and confetti logic
- `img/` — your images already in the folder
